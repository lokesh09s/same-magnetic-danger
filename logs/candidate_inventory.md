Built read-only on 2026-10-05 from decisions.md and the committed logs by two independent agents: one read decisions.md end to end, the other started from git history and the evaluation logs (code and notes by Claude Code (AI)).

Every Δ log-loss and CI below is re-checked against its committed source line by `paper_template/verify_numbers.py`; in LaTeX these values are the macros `\InvDelta<ID>`, `\InvCIlo<ID>` and `\InvCIhi<ID>`, where ID is the row number in letters (1 = A, 27 = AA).

**Definition used.** A candidate is a feature or model that was evaluated against real labels to see whether it adds information to the alarm-level baseline:
- by Δ log-loss against model A, C or C_CV;
- by the magnetic-twins test;
- or by a filter test.
Gate diagnostics, reproduction runs, decision rules and label-blind checks are not candidates (see Excluded).
